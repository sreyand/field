# FIELD — interactive UI concept

Open `index.html` in a browser, or double-click `Open FIELD.cmd` on Windows. No installation, server, or internet connection is needed.

This is a mockup using sample Windows paths. It does not access your filesystem. Demo changes last until you reload the page.

## The mapping idea

A field is a personal view over existing files and folders. A file can belong to several fields through references to its single original location. Subfields provide depth within an interest. Shared references reveal overlaps automatically; personal threads capture ideas and influences.

The demo opens on the big FIELD map. Select **Soundtracks**, open **Blade Runner 2049 — OST**, then follow its membership into **Music / Film scores** or **People / Hans Zimmer**. The original Windows path remains the same.

## Try it

- Browse **Fields**, open a primary field, then enter its subfields.
- Select any connection label on the big FIELD to inspect its meaning and shared files.
- Drag fields to rearrange the map, or use the zoom controls.
- Use **Map files** inside a field to reference a sample file in another field. Shared-file connections update automatically.
- Use **Connect fields** to draw a personal thread with a label and note.
- Create fields and nested subfields, search sample names and paths, and favorite files or fields.

## Intentionally outside this mockup

Windows filesystem integration, folder indexing, stable file identity after renames/moves, permission handling, watchers, previews of real files, and persistent catalogue storage. A native implementation would resolve these underneath the same interface.

The supplied FIELD logo is included unchanged. The collection illustrations are drawn in CSS and SVG. All assets are local.
